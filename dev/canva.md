# Canva の絵（11/8〜）

しょーくんの依頼（11/8）：「Canva の作成に移行しよう。一度に大量に作ると規制がかかるかもしれないから、時間かかってもいいし、ゆっくりやってね」。順番は決めていないので全部。絵柄は 4案（ネオン・ぷにぷに3D・パステル手描き・ドット絵）から **A ネオン** に決定。

## 作るもの（ぜんぶ）
- おばけ 45体（＋状態で かわる かえ絵）
- 台ごとのハンドル 9つ・台の奥の景色・砲台・タイトルの絵・お店／図鑑のアイコン・ボタンやフレーム

## おばけの作り方
1. Canva の generate-image（正方形）。**参考の絵に うさぎおばけ（MAHaRoS65JU）を わたす**と 絵柄がそろう。文は：
   「パチおばのおばけ（参考の うさぎおばけと 同じ絵柄・同じタッチ。うさぎの耳やリボンは つけない）：イタズラ好きの白いおばけ＋◯◯の特ちょう（見た目の部品）。おばけは1体だけ・正面向きの全身を大きく、まわりに少し余白。ゲームのキャラクターの絵。絵柄：ネオンサイン風（こい紺の無地の背景に、◯色の光るネオンの線でふちどり、体は白くほんのり光る）。かわいい。文字なし」
   - ネオンの色は ENEMIES の color に近い色。ボス・中ボスは「少し大きめ」など。
   - **いたずらの説明（分かれる・とぶ…）は 文に入れない**（絵に描かれてしまう。わたげの1回目は 小さいわたげが 2つ ついた）。見た目だけ書く。
2. 状態で 見た目が かわる おばけは、できた絵を 参考にして「◯◯だけ なくした絵に。ほかは そのまま」で かえ絵を作る（位置が そろう）。
3. remove-background で 背景けし。**それだけだと ネオンの光が けずれる**（こい色の部品＝くまの ツボ なども けずれる）ので、`dev/canva/neoncut.py もとの絵 背景けし 出す_full.png` で、体は 背景けしの形・まわりの光は もとの絵の「背景の こん色との ちがい」から すけすけにする。
4. `dev/canva/pack.py` が `_full.png` を切りぬいて WebP（q90）にして SPRITE_SRC の行を出す。かえ絵の組（sprites.json の groups）は 同じ わくで 切るので、入れかわっても体が ずれない。大きさは sprites.json の size（[w, by]：w＝半径に対する絵のはば、by＝絵の下はし）。かえ絵の 体が ずれているときは place（[dx,dy,倍率]、200×200 の 絵の 点で）で そろえる。
5. ここで 取れる絵は 200×200（Canva の見本の大きさ。もとの 1264×1264 は この作業場から ダウンロードできない＝media.canva.com は 通らない）。おばけは この大きさで足りる。
   **大きい絵（台の奥の景色など）は「ページの見本を 切って 読む」**（11/8 ためし・草原で 成功）：作業用デザイン「パチおば 背景 作業用」（DAHaSyBw7z8）を read-design で ひらき（open_transaction）、480×428 の ページを 8まい 足して、それぞれに 絵を 944×1680 の 大きさで ずらして 置く（left 0／-464、top 0／-417／-835／-1252）。edit-design の 返りの 見本は 600×535（1.25倍）なので、8まいを つなぐと 1180×2100 の 絵になる。おわったら edit-design を cancel（デザインは 保存しない）。ゲームには 幅720 の WebP（約45KB）で。
6. たしかめ：`dev/sim/mk.py` のあと `python3 shot.py out.png "$(sed s/__STAGE__/0/g sprcheck.js)" 60`（0＝草原）。台に その台の おばけと かえ絵が ならぶ。sprcheck.js は おばけの tick を 止めて 状態を そのまま 見せる。エラーは `sprerr.js`（その台の おばけ × 状態。1分くらい。全部の drawcheck.js は 30分でも おわらない）。かえ絵の 状態を 足したら 両方の 表に 足す。

## ゲームの中のしくみ
- `SPRITE_SRC` に絵、`sprOf(e)` が いまの絵（ENEMIES の `sprKey(e)` で かえ絵の名前）。絵があると drawGhost は back・skin・front・top・顔を描かない。絵の上に かさねる 効果は `over(e,r,t,P)`（洋館の まとめは 「Canvaの絵の かえ絵と 上に かさねる 効果（洋館）」の区切り）。
  → 状態で出る効果（たて・まほうじん・ふきだし など）を フックの中で描いている おばけは、絵に かえるときに その効果を 絵の上に 描くよう 分ける（森より先の台で 必要）。
- ボスのHPバーは `sprTop(e)` で 絵の上に出す。

### みんなの きまり
- 絵柄は A ネオン。参考の絵に うさぎおばけ（MAHaRoS65JU）や、その台で もう作った絵を わたして そろえる。文字は 絵に 入れない（文字は コードの まま）
- 中身（遊び方・数字・あたり判定・動き）は かえない。見た目だけ。ふえる・へる 部品は 勝手に 足さない
- 見た目の 注文は dev/plan.md の その台の「見た目」を そのまま 文にする（しょーくんは 「書いたものを そのまま」が すき）。ただし 草原の まるい月は しょーくんが OK した
- 遊びやすさ：台の まん中は 暗めで すっきり（玉・杭・おばけが 見えるように）。plan.md に ある 色の ちゅうい（属性の 色と まぎれない）を まもる
- 動く絵（drawBack・drawFront・ギミック・属性の しるし など）は コードの まま 残して、止まった 絵だけ 画像に する
- 軽さ：画像は WebP、毎フレームは 絵を 1まい 描くだけ（CLAUDE.md の 軽さ）。背景・枠は 幅720 くらいで 1まい 約50KB まで
- たしかめ：構文（node）・dev/sim の sprerr.js（エラー0）・スクショで 見る。commit の おわりに Co-Authored-By と Claude-Session の 2行
- しょーくん：市販のビデオゲームみたいに クオリティ高く（11/8）

## 台の奥の景色と 台の枠（11/8〜。1. で 作った しくみ。2.・3. も これで）
### ゲームの中の しくみ
- 絵は `ART_SRC`（index.html。`〇〇_bg`＝奥の景色、`〇〇_frame`＝台の枠。〇〇 は STAGES の style）。中身は **dev/canva/art.py が 書きかえる**（「ART_SRC ここから」〜「ここまで」。手で 書かない）
  - x,y,w,h＝台の座標で 置く場所。景色は アーチの はば（RO*2+8＝340）で 下を H-6 に そろえる。枠は FR（x -45〜405・y -60〜740。450×800 を 900×1600 の 絵で）
  - 枠だけ：base（絵の外を ぬる色。枠の ふちの 色 × art.json の basek（ふつう .85））・glow（光る点 [x,y,半径,色]）・cut/lift（下の板を よせる。下を 見て）
- 台の build で `stageArt(c,V,'〇〇_frame','〇〇_bg')` を よぶ（見本は buildMeadow）。中で：画面ぜんぶを base で ぬる → 枠の絵 → アーチの中（fieldPath で clip）に 景色。glow は G.fruits に入って、draw() で ゆらゆら光る（FEVER で 強く）
  - そのあと build は コードの まま 描くもの：レール rails・ヘソ hesoCup・杭 drawStake・台の あたりの ある物（森の 切り株、洋館の シャンデリアと 燭台 など。杭や ろうそくの 場所と つながっている物）
  - 動く物（ホタル・星の またたき・手前の草・木の実・きのこ・ろうそく・drawBack/drawFront）は 今までどおり コード
- 手前の 地面（11/8 砂漠〜。杭と つながった 大きな物を コードで 描く台）：art.json の 景色に `"ridge":{"y":[上,下],"w":[R,G,B の おもみ]}` を 書くと、art.py が その はばの中で 地面の 光る ふちの 線を さがして ART_SRC の ridge（台の座標の 点）に 入れる。build で 大きな物（砂漠の ピラミッド など）を 描いたあと `artFront(c,'〇〇_bg')` で 線より下を もう一度 かさねる → 大きな物の すそが 手前の 地面の うしろに かくれる（上の ふちは 7 だけ だんだん すける。切りぬいた 絵は 1回だけ 作る）。大きな物は すそを 線より下まで のばしておく
- 絵は はじめて 使うときに 1回だけ よみこむ（artImg）。よめたら その台を 描きなおす（buildStatic）。まだ よめていない間は base と こい色だけ（artMiss）。台の顔（faceCv）は そのとき とっておかず、よめたら 同じ キャンバスに 描きなおす（faceDraw。ホールに 置いたあとでも かわる）
- 画面の 形：スマホの 縦長では 横は 台の外が 14 だけ（枠の 内がわの ふちしか 見えない）。上の角・アーチの上・下の板が よく見える。背の高い スマホ（y -60〜740 くらい）まで 絵が ある。それより 外（よこ長の PC など）は base の色で、絵の ふちは base に とけこむ
- 下の板：画面の下が 絵の下（740）より 上だと、cut より下を lift まで 上へ よせる（cut〜cut+lift の 行を とばす。草原は 板だけの所なので 目立たない）。台ごとに art.json の cut・lift で かえられる（ふつう cut=608・lift=40）

### 作り方
1. 枠：generate-image（PORTRAIT_9_16）。参考の絵に うさぎおばけ（MAHaRoS65JU）と 草原の景色（MAHaS59YJ0A）か その台の景色。文は：
   「パチおばの台の枠の絵（参考の絵と 同じ絵柄・同じタッチ。おばけや うさぎは 描かない）：〇〇の台の、（plan.md の フレームの 文）。縦長の画面いっぱいに（素材）。まん中に 大きな アーチ形の窓を あける（上は 半円・左右は 下まで まっすぐ。窓の はばは 画面の はばの 4分の3、窓の上は 画面の上から 1割、窓の下は 画面の下から 6分の1）。窓の中は 何も描かない こい紺の無地。（ふちの かざり）。絵柄：ネオンサイン風（光るネオンの線）。かわいい。文字なし」
   - 窓の形は ぴったりで なくてよい（art.py が 窓を さがして 台の アーチに 合わせて ゆがめる。窓の外の かざりは 同じ大きさのまま）。窓の中は **こい 無地**に（窓を さがせるように）
2. 景色：generate-image（PORTRAIT_9_16）。参考の絵に うさぎおばけ と 草原の景色（MAHaS59YJ0A）。plan.md の「見た目」の 中の 文を そのまま。台の まん中は 暗く すっきり
   - 杭と つながっていて コードの まま 描く 物（ピラミッド・オベリスク など）は 文から はずして「まん中は あけておく（あとで 大きな〇〇を 重ねるので、まん中には 大きな物を 描かない）」と 書く
   - 景色は 横が アーチの はばいっぱいに なるので、上の すみ（画面の 上 2割の 左右 4分の1）は アーチで 切れる。月など 大事な物は「画面の 左はしから はばの 4分の1・上から 5分の1」など 内がわに。ずれたら その絵を 参考にして「〇〇の 場所だけ かえた絵に。ほかは そのまま」で 作りなおす（砂漠の 三日月で うまくいった）
   - 先に 景色を 作って、枠は その台の 景色を 参考の絵に わたすと 色が そろう
3. 大きく 取る（ここから ダウンロードできないので ページの見本を つなぐ）：作業用デザイン DAHaSyBw7z8 を read-design（open_transaction）→ edit-design で 480×572 の ページを 6まい 足す → read-design（design_content）で ページの id → 1ページずつ edit-design の insert_fill で 絵を 944×1680 で 置く（left 0／-464、top 0／-554／-1108）。返りの 見本は 503×599（1.048倍）→ その場で 見本の ファイル（[Image: source: …png]）を コピー → `python3 dev/canva/stitch.py 出す.png 1 2 3 4 5 6` で 989×1760 に つなぐ。おわったら edit-design を cancel（保存しない）。1つの transaction で 何まいも つづけて できる（同じ ページに 上から 置く）
4. つないだ絵を dev/canva/frame/〇〇_full.png（枠）・dev/canva/bg/〇〇_full.png（景色）に 置いて、dev/canva/art.json に 足す → `cd dev/canva && python3 art.py 見本.png`（WebP は dev/canva/art/。見本.png は 枠と 景色を かさねた 絵）
   - 枠の glow：光る点が 多すぎ・少なすぎなら art.json の "glow"（明るさの しきい。ふつう 130）。数は 明るい方から "nglow"（ふつう 24。毎フレーム 光らせるので 多くしない）
5. その台の build を stageArt に して、コードの 絵（空・丘・枠の木目 など）を けす。dev/sim の sprcheck.js で スクショ（390×780）、背の高い・短い・よこ長の 画面も 見る（窓の ふちの ずれ・すきま・下の板）
