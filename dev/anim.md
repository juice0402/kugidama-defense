# 動き（アニメーション）（11/9〜）

しょーくんの依頼（11/9）：「ボタンの切り替えとか、画面の切り替えとかに 可能な限りアニメーションを加えて欲しい。弾とかセットするときに カチャって感じとか、タワー購入を投下したときに タワーの銃口が一回回るとか。ロビーとか、セット画面も、コンシューマーゲームみたいに リッチなアニメーションがほしい」

## きまり
- 動かすのは **transform と opacity だけ**（box-shadow・filter・背景の位置・文字の ふちどりは 動かさない＝毎フレーム 描きなおしで 重い）
- 動きを へらす 設定（prefers-reduced-motion: reduce）の 人には 出さない：CSS は index.html の「動き ここから」〜「ここまで」の `@media (prefers-reduced-motion:no-preference)` の 中だけ、JS は `reduce` を 見る
- 中身（遊び方・数字・あたり）は かえない。ただ 1つ：タワーを 置いたときの さいしょの 1発は、まわり おわってから（0.3秒 → 0.57秒）
- ずっと 動く ものは へらす（ロゴの ふわふわは 11/9 に はかって 重かったので やめた：タイトル 11% → 55%）

## しくみ（index.html）
- CSS：「/* 動き ここから」〜「/* 動き ここまで */」（UI_ART の すぐ上）。`--spring`（ぽよん）・`--soft`（すっ）
- JS：「動き（11/9）」の 区切り（hideOverlays の 上）
  - `wipe()`：画面の切りかえ。ネオンの ふちの 5まいの 板（#wipe）で おおって、上下に ひらく（シュッの 音 sfx.swoosh）。切りかえた **すぐあとに** よぶ（切りかえは 待たない＝流れは 前と 同じ）。openHub（台・結果・タイトルから）と startStage で よぶ
  - `sheetShow(e)`／`sheetHide(e)`：シート（買う #buy・もどる #quit・ためし #testSheet・杭／砲台 #sheet）。しまうときは `.out` で 下へ すっと → 0.21秒で hidden（とちゅうは さわれない。とちゅうで また 開くと すぐ 出る）
  - `stagger(list, cls, max)`：じゅんばんに 出る（--i）。`.ani`＝下から（ロビーの 中身。renderTab で 上の 9こ）・`.ani-r`＝右から（台の シートの 行）・`.ani-c`＝ホールの 台（まん中の 台から）
  - `renderTab(true)`＝じゅんばんに 出さない 描きなおし（買ったあと）
  - `boardIn()`：台に 入ると コイン・WAVE が 横から、もどる・ハンドルが 下から
  - `setCoins(true)`：ロビーの コインが くるくる へる（数えている とちゅうに 描きなおしても 行き先だけ かえる）
  - `coinFly(el)`：買った カードへ 財布から コインが とぶ。カードは `.got`（ぽんっ・光が はしる）と `.getpop`（+1／GET!）
  - `bump(el)`：ぽんっ（台の コインが ふえたとき。0.15秒に 1回まで）
  - タワーを 置く：`towerDrop(p)`（T.land＝TLAND 0.62秒）。drawTower で 上から 大きく 落ちて（影）→ 杭に ついて 少し つぶれる、drawGun で `landSpin(T)` だけ 1回 くるっ（さいごは ねらいの 向き）。update で 杭に ついた 瞬間に 光の 輪・火花・少し ゆれる。音は build → land（ガシャン）→ spinup（ヒュイン）
- 音（sfx）：swoosh（画面の 切りかえ）・lid（セットの 箱の ふた カチャン）・land（タワー ガシャン）・spinup（銃口 くるっ）

## どこが 動くか
- ボタン：押すと きゅっ（.93）、はなすと ぽよん。金の ボタン（買う・つぎへ）は 光が さっと はしる
- タイトル：ロゴが 上から ぽんっと 落ちる・スタートが 下から
- ロビーに 入る：看板が 上から・タブが 下から・看板の 文字が ネオンみたいに ちかちか ついて・うしろで 光が ゆっくり まわる・財布の コインが ときどき くるっ
- タブ：えらんだ 光（.tsel）が すべる・アイコンが はねる・中身が その向きから すべって 入る・カードが 上から じゅんばんに
- ホール：台が まん中から じゅんばんに 下から
- 玉のセット：箱の ふたが ぱかっ（カチャン）→ 玉が じゅんばんに はまる。はめると 玉が 上から 入って 少し まわって とまる（カチャッ）・穴が はねる・光の 輪・火花・箱が ゆれる。割合の 帯が のびる
- お店：買う シートが 下から ばねで（絵が くるっと 出る）・買うと カードが ぽんっ・+1／GET!・コインが とぶ・財布の 数が へっていく
- 台：入ると 画面の切りかえ・コインと ハンドルが 出てくる。杭の シート・砲台の シートは 下から・行が 右から じゅんばんに・強さの 点が ぽんぽん・経験値の バーが のびる。タワーを 置くと ドスン＋くるっ
- 結果：行が じゅんばんに・ボタンが 下から。トースト（お知らせ）は ぽよん

## たしかめ
- `dev/sim/animrec.py 出す.webm [shots]`：ほんとうに タップして タイトル → ロビー → タブ → 買う → セット → 台 → タワーを 置く → もどる を 動画に（shots で とちゅうの スクショも animshots/ に。スクショを とると 動画に へんな コマが 入る）
- 重さ（CPU 6倍おそい・dev/sim/uiperf.py など）：
  - ずっと（3秒あと）：タイトル 11%（前も 11%）・ロビー 台のタブ 17%（前 14%。まわる 光で +3%）・セット 17%・玉 15%・砲台の シート 3%（前 6%）・台で 遊んでいる 93%（前 94%）
  - 切りかえの 0.8秒くらいは 動きの ぶん 重い（タブの 切りかえ 2秒の 間で 62% ⇔ 動き なし 34%）。動くのは transform と opacity なので 絵は なめらか
