# iPhone・iPad と アプリに する ための メモ（11/9）

しょーくん：「さいごは iOS で アプリとして 公開したい」

## 11/9 に 直した こと（いろいろな 画面で ためして 見つけた もの）

- iPad の 横むき・パソコン・横むきの スマホで、お店の「買う」と 台を 買う シートが 画面の 上に きえていた
  - シートが 下から 出てくる とちゅうに ボタンへ フォーカス → スクロールしない はずの #hub が 736px ずれていた
  - フォーカスは ぜんぶ `focus({preventScroll:true})`。#app・#hub が ずれたら すぐ 0 に もどす
- iPad で 9台 あそぶと キャンバスの メモリが 227MB（iOS は 合計 およそ 224MB を こえると 新しい 絵が まっしろ）
  - sprite の とっておく 絵を 40MB まで（しばらく 使っていない 絵から すてる）・大きい 画面は 細かさ 1.3倍まで・地面の 切りぬきは いまの 台だけ
  - iPad Pro（1024x1366x2）227 → 127MB、iPhone（390x844x3）93 → 79MB。見た目と 重さは 前と 同じ（くらべた）
- クリア・ゲームオーバーの リボンが 右に 13px ずれて、右の おばけが 画面から はみ出していた（スマホ ぜんぶ）→ まん中に
- はば 320 の スマホ：見出し「お店・ギミック」が コインに かぶる・「ノーマルタワ／ー」で おれる・「3,000 でアンロ／ック」→ 字を 少し 小さく・ボタンは ことばの 切れめで おれる
- iPad の 横むき・パソコン：お店・セット・図鑑の 一覧が 横いっぱい（1440px）に のびていた → まん中の はば 720 に
- ボタンを 2回 すばやく タップすると、2回目が 出てきた シートに あたっていた：「もどる」→ 出て すぐ きえる、お店の カード → そのまま 買える、杭 → タワーが 建つ
  → シートは 出て 0.35秒は タップが きかない（もどる・買う・タワーの シート・ためし。とじる とちゅうに また 出した ときも）
- iPhone の Safari だけ：
  - 横に すると 字が かってに 大きく なる → `-webkit-text-size-adjust:100%`
  - ボタンを おした ときの へこみ（:active）が 出ない → touchstart を 1つ 登録
  - 2回 タップ・2本ゆびで 画面が 大きく なる → `touch-action:manipulation`・gesturestart を 止める・viewport の user-scalable=no（アプリでは きく）
  - iPad で 絵を 長おしすると ドラッグで 持ち上がる → `img{-webkit-user-drag:none}`
  - 電話の あとなどで 音が 止まった とき、ハンドルを 回すだけ（クリック なし）だと 鳴らなかった → 指を はなした とき（touchend・pointerup）にも 音を 用意
  - color-mix（iOS 16.2 から）の 前に ふつうの 色を 書いた（それより 古い iPhone でも 色が 出る）
- 動きを へらす 設定を、あそんでいる とちゅうで かえても すぐ きくように

## iPad 用に 大きく（11/9 しょーくん「iPad 用にも 最適化して」）

- 画面が 大きい ときは、ゲームの 画面 ぜんぶ（#app）を uiZ 倍に 大きく する。中の つくりは スマホと 同じ まま（中の 広さ＝画面÷uiZ）
  - uiZ ＝ はば÷440 と 高さ÷880 の 小さい ほう（1.06 より 小さければ 1、いちばん 1.6）。iPad たて 820x1180 → 1.34、iPad Pro 13 たて → 1.56、iPad よこ → 1（高さが スマホと 同じ くらい）
  - CSS の `zoom` は iPhone・iPad の Safari で 指の 位置が ずれる バグが あるので つかわない（transform:scale）
  - 台の キャンバスは 細かさ×uiZ（画面の 点と 1:1・メモリは 前と 同じ）。台を タップした 位置は ÷uiZ。CSS の vw・vh は `--vw`・`--vh`（中の 広さの 1%）
  - 中の はばが 900 以上（iPad よこ・パソコン）は #app.wide：お店・図鑑は 2れつ、持ち玉は 5れつ、まん中の はば 760
- 枠と 中身の すきま（しょーくん「ボタンと 枠の 余白」）：枠の 絵の 光る ふちの 内がわを はかって（パネル 上37 左33 下32 右34・カード 上42 左36 下34 右36 点、
  9わけ 88点・はみ出し 8点）、ボタン・字が ふちから 5px（字は 4px）より 近い 所を さがす（devsweep の SPACE=1）。
  シート・買う・結果の パネル、お店の カード、持ち玉、セットの 帯の「へんしゅう」、図鑑・タワーの 行の 上、×2 の しるし を 広げた

## ためす 道具（dev/sim）

- `devsweep.py`：11の 画面の 大きさ（iPhone SE・15・Pro Max・Safari の バーあり・はば 320・Android・iPad たて／よこ／分割・横むきスマホ・パソコン）で
  タイトル〜ロビー6タブ〜買う〜台〜シート〜もどる〜クリア〜ゲームオーバー〜エンディングを 撮って 一覧に。はみ出し・字の 切れ・ボタンの 重なり・小さい ボタンを 自動で さがす
  （_sweep/<機種>.png と report.txt。一覧の 中の 台えらびの となりの 台・スクロールの 下の カードは わざと 見切れているので 気に しない）
- `animstress.py`：すごく はやい タップ・動きの とちゅうで とじる・タブ れんだ・アプリを 切りかえて もどる を、ふつうと「動きを へらす」の 2回。
  おわらない 動き・見えない まま の ボタン・しまいかけの シート・のこった 部品・エラー を さがす（11/9 は 0）
- `SPACE=1 python3 devsweep.py _sweepS 機種,…`：上に くわえて 枠と ボタン・字の すきま（_sweepS/space/ に 切りぬき）。`panelshots.py 393x852x3`：パネルを 1つずつ 大きく 撮る
- `canvmem.py 1024x1366x2`：9台 あそんだ あとの キャンバスの メモリ。iPad Pro で 150MB 以下を めやすに

## アプリに する しくみ（11/9 しょーくん「公開の しくみは 司令塔の ほうで できてる」）

- juice0402/ios-kobo（【ios】の チャットが 作った・公開）：GitHub Actions の Mac（公開リポジトリなので 無料）で 組み立てて TestFlight → 審査。Mac は いらない
- パチおばは apps/pachioba/（app.json・icon.png・store/ja・pages.json・ART.md）。ゲームは app.json の game.ref の コミットを そのまま 同梱（Google Fonts は prepare.py が ファイルに して 同梱・ネットなしで 動く 点検つき）
- 11/9 に しょーくんと 決めた こと：アイコンは タイトルの 絵の アーチと おばけ5体（A）・配信は 日本だけ・英語の 名前は PachiOba・ブラウザ版は まだ 工房に ない（サポートの ページは 工房の トップへ）
- ゲームの 側で やった こと（11/9）
  - アプリの 中だけ `window.APP_PLATFORM='ios'`・`APP_HAPTIC(kind)`。振動：玉を はめる light・持ち上げ select・タワー着地 medium・買う／アンロック／クリア success・FEVER heavy・ボス出現 warning・ゲームオーバー error
  - アプリでは ためしモード（ロゴ5回 タップ）は なし（審査 2.3.1 かくれた 機能）
  - ストアの スクショの 場面：`#shot=hall|set|shop|play|boss:台`（navigator.webdriver の ときだけ。セーブは べつの 名前）。app.json の screenshots の 台本が location.hash を かえる
  - app.json：safeArea "ignore"（ゲームが env(safe-area-inset-*) で よける）・zoom "game"（iPad は ゲームの applyZ）・iPhone は たて だけ・iPad は 全部の 向き
  - ふちの 色（上の 島・下の バー）は こい 紺 #07040f（app.json の background も 同じ）
- まだ 手で やる こと（App Store Connect・初回だけ）：アプリの 作成（主な 言語＝日本語）・価格（無料）・配信の 国（日本だけ）・App の プライバシー（データの 収集なし）・年齢区分・審査の 連絡先・TestFlight の テスター
