## シナジー：全部の組み合わせ（しくみで全部うめる）
1. **属性×属性**：どの2つの組み合わせにも「わざ」（COMBO）がある。同じ2つは「とくしゅ効果」。新しい台の担当は、その台の2属性 × それまでの全属性（＋その2つどうし）のわざを全部作る（名前・色・説明・効き目）。
   - 森まで15こ。洋館で13こ、砂漠17、雪山21、火山25、魔王城29、宇宙33、天国37 → 全部で190こ。
2. **属性×タワー**：どのタワーも、玉でついた属性・とくしゅ効果・わざを、そのタワーの撃ち方で出す（`applyEff`）。属性タワーは、同じ属性弾1つでとくしゅ効果、ちがう属性でわざ。特別なタワー（サウンド・かがみ・たつまき…）は、撃ち方に合わせた出し方を決める（例：サウンド＝波の中みんなに属性、とくしゅ・わざは2体まで）。
3. **属性×ギミック**：属性弾が当たると、その砲台のギミックにも、砲台と同じ属性・とくしゅ効果・わざが宿る（のこり時間も同じ）。宿ったギミックは、ギミックごとの技を出す。
   - バンパー：玉がはね返るたび、その属性の輪がはじけて、まわりのおばけにつく
   - 回転十字：まわるうでが、その属性をまとって、近くのおばけにつく
   - 引きよせツタ：引きよせた玉に、その属性が宿る（次に当たった砲台・おばけに属性を運ぶ）
   - 新しいギミックも、宿ったときの技を必ず決める
4. つまり「属性A×属性B×タワー×ギミック」は、わざ(A+B) を、そのタワーの撃ち方と、そのギミックの技の両方で出す。どの組み合わせでも何かが起きる。

## コードのしくみ（台ごとの中身は、なるべく「データ＋小さな関数」で足す）
台・属性・タワー・ギミック・おばけ を足すときに、共通のコードの if のくさりをふやさずにすむように、次の「フック」で足す（森のあとの土台づくりで用意する）。

- `ELEM[k]` … `name,color,tag`（説明のタグの文字）, `part`（粒の種類）, `on(e,lv,dmg)`（敵につく）, `has(e)`（いまついているか。敵の上のわざ用）, `tick(e,dt,rd)`（状態の時間を減らす等）, `mark(e,r,t,ga)`（おばけの体の上の絵）, `speed(e)`（動きの倍率。0で止まる）, `special(e,dmg)`（とくしゅ効果）。
- `SPECIAL[k]`・`COMBO['a+b']` … `name,color,desc` と `fx(e,dmg)`。`comboKey` は `EL_ORDER` の順。
- `applyEff(e,eff,dmg)` … eff は `{combo}|{sp}|{el,lv}`。タワーの弾・音の波・ギミック・新しいタワーは全部これで効かせる。
- `FXK[kind]` … 粒の種類ごとの `upd/glow/draw`（新しい粒を足せる）。
- `ENEMIES[t]` … データ（hp,sp,r,color,reward,boss,call,calls…）＋フック：`init(e)`, `tick(e,dt,o)`（いたずら。o.held＝ねむり・しびれ中、戻り値やe.mvで動きを変える）, `ballHit(e,b,nx,ny)`（玉が当たった。trueでダメージなし）, `bulletHit(e,u)`（タワーの弾。trueでよけた）, `dmgK(e)`, `death(e)`, 絵：`back(e,r,t,P)`・`front(e,r,ey,t,P)`・`top(e,r,t,P)`・`mouth(e,r,ey,t)`・`alt(e,r,t,P)`（体ごと別の絵）, `ey`。
- `TOWERS[k]` … データ＋ `shoot(p,T,D,R)`（撃ち方。trueなら自前で撃った）, `gun(T,R,kick)`（砲身の絵）, `over(p,T,t)`（頭の上の絵）, `tick(p,T,dt)`（てんしタワーのような手助け）。弾の種類は `BULLETK[kind]`（`step(u,f)`,`draw(u)`）で足せる。
- `GIMMICKS[k]` … データ＋ `step(b,p,T,h)`（玉への力）, `collide(b,p,T)`（当たり方を変える。trueで自前）, `hit(p,T,b)`, `draw(p,T,t)`, `charged(p,T,eff,b)`（宿ったときの技。玉が当たった・はね返ったとき）, `aura(p,T,eff,dt)`（宿っている間ずっと）。
- `STAGES[i]` … `name,style,accent,layout,foes,hp,grow,bossHp,fly`（ホタルの色）, `build(c,V)`（台の止まった絵）, `setup(L)`, `tick(dt,f)`（ステージギミック）, `ball(b,h)`（ステージの物と玉の当たり）, `drawBack(t)`・`drawFront(t)`。
- `BOARDS[i]` … `stage,price,need,desc,thumb`。開き方：`need` の台をクリアしていて、`price` があればコインで買ってある（セーブ `bought`）。
